# 
Biological Dataset Selection and Documentation

This project focuses on the selection and documentation of a publicly available biological dataset for bioinformatics research. The objective is to explore how biological and genomic datasets can be obtained from open scientific repositories and used to investigate meaningful research questions.

The dataset was selected from the NCBI Gene Expression Omnibus (GEO) database, a public repository containing functional genomics data. The selected dataset, GSE42568, contains gene expression profiles associated with breast cancer and normal breast tissue samples. It provides an opportunity to explore differences in gene expression between cancerous and non-cancerous tissues.

The primary research question is: How do gene expression patterns differ between breast cancer tissues and normal breast tissues? Understanding these differences can help identify genes associated with breast cancer and provide a foundation for further bioinformatics and computational biology research.

The project involves identifying the dataset source, examining its characteristics, documenting the sample information, and understanding its potential research applications. Key details include the dataset accession number, experimental platform, sample composition, and data availability. This task focuses on computational research planning and dataset documentation without performing laboratory experiments.

Dataset source: "NCBI GEO – GSE42568" (https://www.ncbi.nlm.nih.gov/geo/query/acc.cgi?acc=GSE42568)

This project demonstrates introductory skills in biological data discovery, scientific documentation, research question formulation, and the use of public genomic databases. It also provides a foundation for future work in gene expression analysis, cancer bioinformatics, and computational biology.
